# Real-Ghost regression suite

This suite starts Ghost with a temporary database, synthetic publication data, a random loopback port, and six themes generated by the current CLI. It only reads code/dependencies from the Ghost installation you select. Your normal Ghost database, content, settings, and port are untouched.

## Setup

Use Node supported by your Ghost installation. The pinned CI target is Ghost 6.63.0 on Node 24.20.0. Install project dependencies, build the CLI, and install Chromium:

```sh
npm ci
npm run build
npx playwright install chromium
```

Set `GHOST_E2E_ROOT` to the **version directory** containing Ghost's `index.js`, `package.json`, and installed `node_modules`, not the publication's content directory. For example, in PowerShell:

```powershell
$env:GHOST_E2E_ROOT='C:/path/to/ghost/versions/6.63.0'
npm run test:e2e:preflight
npm run test:e2e
```

On Linux/macOS:

```sh
GHOST_E2E_ROOT=/path/to/ghost/versions/6.63.0 npm run test:e2e
```

Without an existing installation, install the pinned Ghost package into a dedicated directory (`npm install --prefix .ghost-runtime --no-audit --no-fund ghost@6.63.0`) and use `.ghost-runtime/node_modules/ghost` as the root. Linux CI also installs browser OS dependencies with `npx playwright install --with-deps chromium`.

## Coverage and boundaries

- Vanilla CSS and Tailwind; Light, Dark, and Auto (both system preferences).
- 1280px desktop and 390px mobile; visible cards, image loading, no horizontal overflow, mobile navigation.
- Genuine Koenig-rendered editor cards, native comments iframe, transparent comments color scheme.
- Related stories, public-only tags, previous/next links, duplicate heading IDs, TOC focus behavior and empty states.
- Real signed Ghost sessions for free and comped paid members; protected content must not leak to visitors or free members.
- Disabled and invite-only membership settings.

This is a Chromium regression matrix, not a guarantee for every host theme, browser, Ghost version, or editor card. Media checks cover layout and controls, not video codec playback. Payment and email writes are blocked; the suite does not charge anyone or send subscriptions. Real comments load Ghost's client assets, so network access is required.

HTML/JSON reports and failure traces are generated in `playwright-report/` and `test-results/`. Each layout step saves a full-page screenshot. The suite stops on the first failure to avoid rebuilding the isolated publication repeatedly; fix that failure and rerun the full matrix. Normal completion cleans up the fixture. Failed fixture initialization preserves only its own temporary directory for diagnosis and prints that path.
